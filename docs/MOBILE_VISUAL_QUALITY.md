# 手機畫質與 N-GO 球拍測試版

基底：V8 `e2b7152`。分支：`task/codex/mobile-visual-quality`。

由一個 GPT-6.1 Terra 工作代理實作球拍和渲染調整，主代理審查、補手機設定入口與做瀏覽器檢查。沒有再開其他工作代理。

## 改動

- 開啟手機 WebGL 抗鋸齒。
- 初始化、切畫質、resize 共用 `getRenderPixelRatio()`，不再一律鎖死 DPR 1.4。
- 依實際裝置 DPR 取較小值：節能最多 1.2、平衡 1.6、清晰 2、超清 2.5。不強制每台手機跑 DPR 3。
- 手機選單「畫質音效」可直接選四檔，原有畫質入口仍保留。檔位標籤移除不固定成立的 720p／1080p／原生解析度字樣。
- 人偶、匹克鵝、黑天鵝共用雙面圓角拍面、森林綠護邊、奶油色葉子與 N-GO 圖樣、握柄環帶。紋理 512×640，共享幾何與材質。
- 保留 `pPad`、`gPad`、骨架握拍掛點、碰撞、計分、體感和相機規則。

## 實際檢查

同為 390×844、deviceScaleFactor 3、iPhone UA 的瀏覽器環境：

| 項目 | 線上舊版 | 新測試版清晰檔 |
| --- | --- | --- |
| 渲染 DPR | 1.4 | 2 |
| Canvas 像素 | 546×1181 | 780×1688 |
| WebGL context antialias | false | true |
| frameSkip | 2 | 2 |

已確認四檔 DPR 切換和 resize 後一致，並檢查手機設定入口、選角、掛拍以及球拍近照。`node scripts/self-test.js` 99 項通過，`git diff --check` 通過。

以上是桌面瀏覽器模擬手機條件，不能當成實體手機 FPS 或散熱測試。高檔位增加 GPU／記憶體負載；使用者在手機比較清晰與平衡後，再決定預設取捨。

此分支先供手機測試，尚未替換 V8 main／gh-pages。
