一、組織主體與服務性質

1. 研發維運主體：本系統由「國立中興大學匹克球學生學習社群」（以下簡稱「社群團隊」或「我們」）自主研發、維運與進行演算法訓練。
2. 服務性質：智慧體感匹克球運動科技、動作分析、教育輔助與數位互動訓練系統。
3. 適用規範：恪遵《中華民國個人資料保護法》及主流應用平台審查標準。

二、同意方式與契約成立（按鈕即同意原則）

本系統於入口頁面提供本政策之顯著摘要與超連結。使用者點擊「🚀 快速進入球場」、「🚀 進入中興球場開打!」或「👟 訪客快速試玩」任一按鈕，即視為您已充分閱讀、理解並同意本政策之全部條款。若不同意本政策，請立即關閉瀏覽器離開。

三、相機影像處理與 MediaPipe 邊緣運算防護

📷 邊緣端即時運算（Edge Real-Time Processing）

當您啟用相機體感功能時，相機視訊畫面僅於您個人設備之本地記憶體中進行即時關節座標萃取與擊球判定。

【零影像上傳承諾】：本系統目前絕不錄影、絕不上傳、亦不在伺服器儲存任何使用者的原始視訊、生活背景或個人容貌影像。每一幀畫面在計算完畢後立即於記憶體中銷毀。未來若因新功能調整，將另行取得使用者明確同意。

🦴 空間骨架關鍵點座標（Pose Landmarks）

演算法自即時影像中計算之資訊，僅為人體 33 處關節點之三維幾何座標（x, y, z 與可信度 visibility），非唯一生物辨識特徵，無法用於反向重現個人面貌或辨識自然人身分。

四、數據收集範疇、處理目的與假名化架構

本系統採用假名化（Pseudonymization）識別架構，以裝置隨機產生之 `playerId` 存檔，不收集真實姓名與密碼：

數據類別 詳細項目說明 處理目的與法定用途 必填性
學號前綴與系級 中興學號前 7 碼（學制+入學年+系所代碼）及推算之系所、年級 識別校園系級歸屬、計算系際排行榜 訪客免填
球員檔案資料 遊戲暱稱、代表頭像、Instagram 帳號（選填） 於遊戲介面、排行榜與球員名片中辨識玩家 IG為選填
數位孿生與歷程 數位孿生球風特徵（`twin_data`：球速、失誤率、近10次擊球）、關卡星級、愛心數（`likes`）、球友關係（`friends`） 建立 AI 數位孿生以供好友非即時對戰、紀錄訓練成長曲線 自動紀錄
技術診斷與安全 IP 位址（經 Cloudflare 處理）、設備類型、相機啟用狀態（`webcam`） API 頻率限制（防阻刷分與攻擊）、排除硬體相容性錯誤 自動產生

五、資料公開範圍與社群能見度宣告

為維護校園良性運動互動與排名樂趣，以下資料將於系統內對其他球員公開：

  • 英雄榜（全體可見）：排名、頭像、暱稱、系所名稱、最高得分與獲讚數。⚠️ Instagram 帳號不會於公開英雄榜中直接洩漏。
  • 球友名片與對抗（球友可見）：互相確認為球友後，好友得檢視您的數位孿生球風雷達圖並發起對戰挑戰；若您有填寫 IG 帳號，球友得透過名片前往您的個人頁面交流。

六、資料用於動作分析與 AI 模型訓練優化

使用者理解並同意，本系統所處理或收集之假名化與去識別化數據，將用於：

  1. 模型訓練與演算法研發：以匹克球及運動動作分析相關之機器學習、深度學習模型訓練、驗證、微調與後續演算法開發為限。
  2. 系統與體驗優化：提升辨識精準度、軌跡預測、運動力學分析及智慧功能改進。
  3. 訓練成果之獨立性：已完成訓練之模型在技術上無法分離特定個別資料之貢獻，因此刪除帳號請求不溯及既往已編譯發布之模型演算法。
  4. 安全承諾：絕不將使用者資料販售、出租予第三方商業廣告商或資料仲介業者。

十、第三方基礎設施與無廣告追蹤宣告

本系統原始碼中絕無嵌入任何第三方商業廣告追蹤 SDK 或廣告聚合聯播網。

系統所採用之基礎架構包括：

  • jsDelivr CDN（`cdn.jsdelivr.net`）：提供開源 MediaPipe 函式庫快速載入。
  • Cloudflare（`workers.dev`）：提供 API 反向代理、HTTPS 加密傳輸通道與防阻 DDoS 之頻率限制。
  • Google Apps Script / Google Sheets：提供雲端排行榜、成績驗簽與球友資料庫之儲存運算。
